# Swipe Launcher

Swipe Launcher - это Android-лаунчер, который позволяет вам управлять своим устройством с помощью свайпов! Вы можете открыть любое приложение, включить фонарик, управлять музыкой - все это с одного экрана.

Вот несколько ключевых особенностей Swipe Launcher:

1. Интуитивный интерфейс: Swipe Launcher предлагает простой и интуитивно понятный способ управления вашим устройством. С помощью свайпов вы можете быстро открыть нужное приложение или выполнить необходимое действие. Это упрощает и ускоряет вашу повседневную работу.

2. Разнообразные действия: Swipe Launcher поддерживает широкий спектр действий, которые можно выполнять с помощью свайпов. Независимо от того, нужно ли вам включить фонарик, настроить яркость экрана или управлять медиаплеером, Swipe Launcher предоставляет вам удобный способ сделать это.

3. Кастомизация: Продукт предлагает множество настроек, позволяющих вам настроить Swipe Launcher по вашему вкусу и потребностям. Вы можете выбрать желаемые действия для свайпов, изменить основной интерфейс и настроить различные параметры.

4. Эффективность и производительность: С Swipe Launcher вы можете значительно сэкономить время и усилия при использовании вашего устройства. Быстрые свайпы позволяют моментально переключаться между задачами и выполнять нужные действия. Это особенно полезно, когда вам нужно быстро ответить на важное сообщение или сделать небольшую задачу.

Swipe Launcher - это отличный инструмент, позволяющий оптимизировать вашу работу с Android-устройством. Благодаря своей гибкости и простоте использования, он подходит для широкой аудитории пользователей. Если вы ищете удобный способ управления вашим устройством, рекомендую обратить внимание на Swipe Launcher.


Работает всё это очень просто. Вам необходимо коснуться экрана в любом месте, после этого перед вами появится меню. Переместите палец на любой из элементов, запустится действие для этого элемента. Все действия и меню проставляются в настройках.

Список поддерживаемых действий:
1. Открыть приложение
2. Открыть новое меню (на месте выбранного элемента открывается новое меню)
3. Работа с фонариком
4. Позвонить
5. Набрать номер (открыть приложение "Телефон" с введённым номером)

Также, при двойном нажатии в любом месте открывается список всех приложений. Сверху будет поиск. Чтобы зайти в настройки можно открыть приложение SwipeLauncher.
При длительном нажатии на приложение в поиске открывается диалог редактирования, где вы можете редактировать приложение (менять название и иконку). Также можно сбросить редактирование (кнопка справа). В этом диалоге также есть 3 кнопки: получить информацию о приложении, удалить приложение, скрыть приложение. Все скрытые приложения можно просмотреть в настройках в соответствующем пункте.

Объяснение некоторых настроек:
1. Все меню - перейти к списку всех меню
2. Изменить лаунчер по умолчанию - перенаправляет на экран настроек с выбором лаунчера по умолчанию
3. Открыть последнее оставшееся приложение - при поиске в списке всех приложений, если запросу удовлетворяет лишь одно приложение, то оно автоматически открывается (не нужно на него нажимать)
4. Нажатие на часы - действие при нажатии на часы (лучше всего поставить открытие приложения часы)
5. Чёрный цвет текста на обоях - если ваши обои очень светлые то, цвет текста на них можно сделать чёрным. (не включается автоматически при установке светлых обоев).
6. Выбрать действие открыть приложение при выборе иконки приложения - при редактировании элемента меню к нему необходимо выбрать иконку и действие, так что если вы хотите, чтобы этот элемент открывал приложение, то вам бы пришлось сначала выбирать иконку этого приложения, а затем действие его открытия, теперь, при выборе иконки приложения действие автоматически меняется на открытие этого приложения


У меню можно менять название (нажмите на название на экране редактирования меню), также можно удалять лишние элементы. При нажатии на название типа действия вы открываете диалог, в котором можно выбрать другой тип и действие. При нажатии на само действие вы открываете диалог редактирования этого действия. Например, если у вас выбрано действие "Открыть приложение", то при нажатии на иконку приложения, вы можете заменить его другим.
