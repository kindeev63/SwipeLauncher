# Swipe Launcher

SwipeLauncher - это лаунчер для Android, созданный для более быстрого управления устройством. Он построен на системе свайпов. Лаунчер полностью настраеваемый. Можно настроить действие и изображение каждого элемента.

Поддерживаемые типы действий:
1. Открыть новое меню - на месте данного элемента открывает заранее заданное меню
2. Открыть приложение
3. Открыть ссылку
4. Включить фонарик
5. Выключить фонарик
6. Изменить состояние фонарика - если включён, то выключить и наоборот
7. Открыть настройки - настройки лаунчера
8. Набрать номер - открыть приложение телефон с заранее заданным номером
9. Позвонить - на заранее заданный номер

Поддердиваемые типы изображений:
1. Иконка приложения
2. Пользовательское изображения - можете загрузить любое
3. Из коллекции - стандартные изображения приложения

При двойном нажатии в любом месте экрана открывается список всех приложений с поиском. При нажатии на приложение оно открывается. При нажатии и удержании открывается диалог, где можно удалить приложение или просмотреть информацию о нём. Если найти и открыть SwipeLauncher, то откроются настройки лаунчера

Если в настройках включена функция открытия последнего приложения в поиске, но необходимо просто найти приложение, то начните поиск с пробела, а затем пишите название приложения - так оно не откроется в результате поиска.

В настройках вы можете определить следующее:
1. Все меню и их элементы
2. Действие при надатии на часы (виджет на главном экране)
3. Цвет текста на обоях (цвет виджета часов) - чёрный или белый (выбирайте, чтобы не сливался с обоями)
4. Открытие последнего приложения при поиске - если под поисковый запрос подходит только оно (вы можете включить или выключить эту функцию)
5. Показ клавиатуры при открытии списка приложений - чтобы сразу же начать поиск (вы можете включить или выключить эту функцию)
6. Выбрать действие открытия приложения при выборе иконки приложения - для более быстрой настройки элементов в меню

Также из настроек вы можете получить доступ к выбору лаунчера по умолчанию, экрану обучения и ссылке на канал приложения в Telegram ([ссылка](https://telegram.me/swipelauncher))

Настроенные меню можно сохранить в zip файл. Также можно загрузить меню из zip файла.
